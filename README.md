# ResumeCraft – Online Resume Builder 📄

ResumeCraft is a simple and user-friendly web application that helps students, freshers, and job seekers create professional resumes easily. It provides a live preview, customizable templates, and an option to print or save the resume as a PDF.

## ✨ Features

- 📝 Easy-to-use resume creation form
- ⚡ Real-time resume preview
- 🎨 Customizable resume templates
- 👤 Add personal and contact information
- 🎓 Include education, skills, and work experience
- 📄 Print or save your resume as a PDF
- 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive layout
- **JavaScript** – Live preview, template switching, and functionality

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/resumecraft.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Open the project

Navigate to the project folder:

```bash
cd resumecraft
```

### 3. Run the application

Open `index.html` in your web browser to start using ResumeCraft.

No additional installations are required.
